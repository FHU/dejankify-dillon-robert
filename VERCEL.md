1. An overview/outline of the deployment process
The deployment for Vercel was really easy. All I had to do was put in the link to my GitHub repo and give it the environment variables I had set up.
It would probably be a bit more difficult to set up manually, but through GitHub it took almost no effort from me.

2. Pros and cons of the cloud service based on your experience with it.
A pro of Vercel is that it is extremely easy to set up and utilize. I had almost zero trouble with the setup.
The main con, however, is the cost. At our level, the price obviously is not an issue. If we needed to upscale a lot, though, Vercel is a lot pricier than other options.

3. Any challenges or surprises that you encountered
The main challenge I encountered was figuring out how to set up the Google OAuth, but once I got that figured out it was easy to replicate.
The only other surprise I saw was that you have to include EVERY environment variable, even blank ones that (as far as I'm aware) don't do anything.
